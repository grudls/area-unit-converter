# 🌿 เครื่องคำนวณและแปลงหน่วยพื้นที่ดิน (Thai Land Area Converter)

เว็บแอปพลิเคชันมินิมอลสำหรับคำนวณและแปลงหน่วยพื้นที่ดินไทย (ตารางเมตร, ตารางวา, งาน, ไร่) ออกแบบด้วยโทนสีสบายตา สไตล์ Earthy Minimalist รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ

![Preview](preview.png)

## ✨ ฟีเจอร์หลัก (Features)

1. **🔄 แปลงหน่วยทันที (Realtime 4-Way Converter)**
   - กรอกหน่วยใดหน่วยหนึ่ง (ตารางเมตร, ตารางวา, งาน, ไร่) ระบบจะแปลงหน่วยที่เหลือให้อัตโนมัติแบบ Real-time
   - พร้อมปุ่มเลือกขนาดยอดนิยม (50 ตร.ว., 100 ตร.ว., 1 ไร่, 2.5 ไร่, 1 เฮกตาร์)

2. **📜 โฉนดที่ดิน (ไร่ - งาน - วา)**
   - คำนวณตามรูปแบบโฉนดที่ดิน (X ไร่ Y งาน Z ตารางวา) รวมเป็นตารางเมตร
   - แปลงย้อนกลับจากตารางเมตร แยกเป็น ไร่, งาน, ตารางวา พร้อมเศษ

3. **🏷️ ประเมินราคาที่ดิน (Price Estimator)**
   - คำนวณราคาซื้อขายที่ดินจากพื้นที่และอัตราที่กำหนด (บาท/ตร.ว., บาท/ไร่, ราคารวม)
   - สรุปราคาเฉลี่ยต่อตารางวาและต่อไร่ พร้อมปุ่มคัดลอกข้อความสำหรับส่งใน LINE หรือแชทลูกค้า

4. **🎨 ดีไซน์และประสบการณ์ใช้งาน (UI/UX)**
   - Minimalist & Earthy Green Palette สบายตา
   - รองรับ **Dark Mode** และ **Light Mode** พร้อมจำค่าอัตโนมัติ
   - ปุ่มคลิกเดียวเพื่อคัดลอกผลลัพธ์ (Click-to-Copy)
   - ตารางสรุปมาตราวัดพื้นที่ดินไทย (Cheat Sheet)

## 📐 มาตราวัดพื้นที่อ้างอิง

| หน่วย | เทียบเท่า |
|---|---|
| **1 ไร่** | 4 งาน (400 ตารางวา / 1,600 ตารางเมตร) |
| **1 งาน** | 100 ตารางวา (400 ตารางเมตร) |
| **1 ตารางวา** | 4 ตารางเมตร (กว้าง 2 ม. × ยาว 2 ม.) |
| **1 เฮกตาร์** | 6.25 ไร่ (10,000 ตารางเมตร) |
| **1 เอเคอร์** | ≈ 2.53 ไร่ (4,046.86 ตารางเมตร) |

## 🚀 การติดตั้งและเปิดใช้งาน (Getting Started)

เนื่องจากเป็น Static Web สามารถเปิดใช้งานได้ทันทีโดยไม่ต้องรันเซิร์ฟเวอร์:
- ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้

## 🌐 การดีพลอย (Deployment)

สามารถดีพลอยขึ้น **Vercel**, **GitHub Pages**, หรือ **Netlify** ได้ทันทีโดยไม่ต้องตั้งค่า Build Command เพิ่มเติม
